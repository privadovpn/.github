# .github

Community health files and organization profile for [PrivadoVPN](https://privadovpn.com) on GitHub.

- `profile/README.md` — organization profile card shown on the GitHub org page
- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md` — default policies inherited by repositories that don't define their own
- `ISSUE_TEMPLATE/`, `PULL_REQUEST_TEMPLATE.md` — default issue and pull request templates
