# Contributing

This file provides default contribution guidelines for repositories under the PrivadoVPN organization that don't include their own `CONTRIBUTING.md`.

## Reporting Issues

Search existing issues before opening a new one. Include steps to reproduce, expected behavior, and actual behavior.

## Submitting Changes

1. Fork the repository and create a branch from the default branch.
2. Make your changes, following the existing code style.
3. Add or update tests where applicable.
4. Open a pull request describing the change and its motivation.

## Code of Conduct

Participation in this project is governed by the [Code of Conduct](./CODE_OF_CONDUCT.md).
